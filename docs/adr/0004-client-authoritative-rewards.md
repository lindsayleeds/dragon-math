# The device decides progress and rewards, and the server flags anything implausible

On iOS, the device decides unlocks, medals, mastery and dragon prize draws, including offline, and the server accepts the results. We chose this so kids get rewards immediately, even offline, rather than having the server draw rewards when the device syncs. We accept that a modified device could award itself rewards. As a safeguard, the server flags implausible results (impossible times, abnormal reward rates) and hides them from leaderboards and teacher stats, but never takes anything away from the kid.

## Considered Options

- **Server-drawn rewards** ("the egg hatches when you're back online"): cheat-proof, but rewards are delayed offline.
- **Offline play only counts as practice:** safe, but frustrating.
